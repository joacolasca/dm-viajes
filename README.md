# DM Viajes

Rediseño del sitio de DM Viajes, agencia argentina de viajes a medida.

Sitio estático: `index.html` (estructura y plantilla), `styles.css` (estilos), `app.js` (datos y lógica) e `img/` (fotos de Unsplash). Usa Vue 3 desde CDN, sin paso de build.

## Ver en local

```bash
python3 -m http.server 8080
```

y abrir http://localhost:8080

## Publicar

Se despliega en Vercel importando este repositorio, con la configuración por defecto (framework "Other", sin comando de build).
